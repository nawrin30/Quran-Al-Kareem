# Quran Al-Kareem

বাংলা-সমর্থিত Quran reader web app built with HTML, CSS and vanilla JavaScript.

## Run
1. Extract this ZIP.
2. Open the `quran-al-kareem` folder in VS Code.
3. Run `index.html` using Live Server.
4. Internet is required for Quran API data and recitation audio.

## Theme
Use the sun/moon button in the top toolbar to switch between the mint/forest-green light theme and deep forest-green dark theme. Theme choice is saved in localStorage.

## Note
Audio and Quran content rely on external APIs and require internet access.
